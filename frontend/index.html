Backend & API Reference (Java HttpServer · Port 8080)

Start the zero-dependency Java 11+ backend from the backend/ directory:

javac -d out *.java models/*.java
java -cp "out;resources" Main   # Windows
java -cp out:resources Main     # macOS / Linux

Endpoints exposed on http://localhost:8080:

GET  /               → Serves Sentriva web interface
GET  /health         → {"status":"ok","version":"3.0.0","modules":5}
GET  /sample-target  → Built-in test page for live inspection
POST /scan           → Body: {"url":"https://example.com","modules":[true,true,true,true,true]}
